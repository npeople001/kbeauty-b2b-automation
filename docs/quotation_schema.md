# Quotation Schema

## Purpose

This document defines the required input and output structure for internal-review quotation drafts generated by Task 009: Quotation Maker.

The Quotation Maker uses only local buyer data, local proposal message outputs, local brand approval rules, and manually provided quotation input data. It does not send quotations externally, create final commercial offers, automate messages, scrape, search, call APIs, enrich buyers, verify credit, or collect external data.

All quotation outputs are internal-review drafts only.

### Required Input Fields

- `quote_input_id`
- `buyer_id`
- `brand_name`
- `product_name`
- `requested_qty`
- `provided_by`
- `provided_at`

### Recommended But Verification-Sensitive Input Fields

- `unit_price`
- `currency`
- `stock_status`
- `available_qty`
- `expiry_date`
- `moq`
- `delivery_lead_time`
- `price_valid_until`
- `supply_status`
- `approval_status`

These values must come from manually provided quotation input only. The generator must not invent, infer, estimate, or backfill missing commercial values.

### Input Field Definitions

| Field | Meaning | Required | Format | Allowed values | Example | Notes |
|---|---|---:|---|---|---|---|
| `quote_input_id` | Unique ID for a manually provided quotation input row. | Required | Text ID. | Unique value. | `QI-0001` | Must not be reused in the same input file. |
| `buyer_id` | Buyer ID that the quotation line is for. | Required | Existing buyer ID. | Must match local buyer data. | `BUYER-0001` | Must match `data/buyers_master_sample.csv`, scored buyer data, and proposal message data. |
| `brand_name` | Brand name for the quotation line. | Required | UTF-8 text. | Free text, validated against local brand master where possible. | `아누아` | Must not be changed to guessed English names. Approval-required brands must be blocked unless explicitly approved. |
| `product_name` | Product name to quote. | Required | UTF-8 text. | Manually provided text. | `Sample Toner 200ml` | Must be manually provided. Do not invent official product names. |
| `product_category` | Product category for internal review. | Optional | UTF-8 text. | Free text. | `toner` | Use manually provided category only. |
| `sku_or_option` | SKU, package size, shade, variant, or option. | Optional | UTF-8 text or blank. | Free text. | `200ml` | Leave blank if not manually provided. |
| `requested_qty` | Quantity requested or being reviewed for quotation. | Required | Integer text. | Positive integer. | `150` | Must be manually provided. Used for MOQ and total calculation. |
| `unit_price` | Unit price for the quotation line. | Verification-sensitive | Decimal number, blank, or `unknown`. | Numeric value, blank, or `unknown`. | `4.50` | Must come from manually provided quotation input only. Missing value requires price confirmation. |
| `currency` | Currency for `unit_price` and `total_amount`. | Verification-sensitive | Controlled value. | `KRW`, `USD`, `CNY`, `EUR`, `RUB`, `THB`, `VND`, `IDR`, `MYR`, `SGD`, `unknown`, `other` | `USD` | If missing or `unknown`, commercial value is not final. |
| `stock_status` | Stock availability status. | Verification-sensitive | Controlled value. | `in_stock`, `limited`, `out_of_stock`, `unknown` | `in_stock` | Must come from manually provided quotation input only. |
| `available_qty` | Manually provided available quantity. | Verification-sensitive | Integer text, blank, or `unknown`. | Positive integer, blank, or `unknown`. | `500` | Missing or unknown value requires stock confirmation. |
| `expiry_date` | Product expiry date. | Verification-sensitive | ISO date `YYYY-MM-DD`, text month format, blank, or `unknown`. | Date text, blank, or `unknown`. | `2027-12-31` | Must come from manually provided input. Missing value requires expiry confirmation. |
| `moq` | Product-level MOQ. | Verification-sensitive | Integer text, blank, or `unknown`. | Positive integer, blank, or `unknown`. | `100` | Product-level MOQ should be used where available. General MOQ is 100+ units. |
| `delivery_lead_time` | Delivery lead time for the item or quotation. | Verification-sensitive | UTF-8 text, blank, or `unknown`. | Free text. | `20-30 days` | Must be manually provided or clearly marked as default/general. Not a guaranteed final term. |
| `price_valid_until` | Date until which the price is valid. | Verification-sensitive | ISO date `YYYY-MM-DD`, blank, or `unknown`. | Date text, blank, or `unknown`. | `2026-06-30` | Missing value should trigger internal review caution. |
| `supply_status` | Supply availability status. | Verification-sensitive | Controlled value. | `available`, `limited`, `unavailable`, `unknown` | `available` | Must come from manually provided quotation input only. |
| `approval_status` | Explicit approval status for the quoted brand/item. | Verification-sensitive | Controlled value. | `approved`, `approval_required`, `not_allowed`, `unknown` | `unknown` | Required to override future approval blocks. `메디큐브` remains blocked unless explicit approval is recorded. |
| `notes` | Internal notes about the quote input. | Optional | UTF-8 text or blank. | Free text. | `가격은 내부 확인 필요.` | Must not include unsupported claims, final terms, or unnecessary personal data. |
| `provided_by` | Internal person, role, or source that provided the input. | Required | UTF-8 text. | Free text. | `internal_sales` | Used for auditability. |
| `provided_at` | Date the input was provided. | Required | ISO date `YYYY-MM-DD`. | Valid date. | `2026-06-09` | Used for auditability and freshness review. |

## Business Rules

- Output must be for internal review only.
- The schema must not imply external quotation sending.
- `unit_price`, `stock_status`, `available_qty`, `expiry_date`, `supply_status`, and `price_valid_until` must come from manually provided quotation input only.
- The generator must not invent missing commercial values.
- If `unit_price` is blank or `unknown`, `quotation_status` must indicate price confirmation is needed.
- If `stock_status` or `available_qty` is blank or `unknown`, `quotation_status` must indicate stock confirmation is needed.
- If `expiry_date` is blank or `unknown`, `quotation_status` must indicate expiry confirmation is needed.
- If `requested_qty < moq`, `moq_check=fail` and `quotation_status` should indicate MOQ confirmation is needed or not quotable.
- `total_amount` can be calculated only when `requested_qty` and `unit_price` are valid numeric values.
- `total_amount` must not include taxes, shipping, duties, discounts, or incoterms unless manually provided and explicitly supported later.
- `approval_block=true` must prevent external-ready quotation.
- `메디큐브` must remain approval-required unless explicit approval is recorded.
- Brands with `approval_required=true` or `proposal_allowed=false` must not become external-ready quotation items.
- Quotation output must not include `contact_email`, `contact_phone`, `wechat_id`, or `whatsapp` by default.
- Quotation output must not include cosmetic efficacy, medical, clinical, dermatological, before/after, or guaranteed result claims.
- Korean, English, and Chinese text must be preserved.
- CSV outputs intended for Excel/business users must use UTF-8 with BOM, `utf-8-sig`.
- XLSX is preferred for internal business review.

## Validation Requirements

Future quotation outputs must be validated for:

- Required input columns exist.
- Required output columns exist.
- `buyer_id` matches buyer master, scored buyer, and proposal message data.
- `quotation_id` is unique.
- `quotation_status` uses allowed values.
- `approval_block` uses `true` or `false`.
- `moq_check` uses allowed values.
- `required_internal_review` uses `true` or `false`.
- `stock_status`, `supply_status`, `approval_status`, and `currency` use allowed values.
- `approval_block=true` when buyer `approval_block=true`.
- `approval_block=true` when brand is `approval_required=true` or `proposal_allowed=false`.
- `메디큐브` is blocked unless explicit approval exists.
- Missing price, stock, or expiry values produce the correct confirmation-needed status.
- `total_amount` calculation is correct when applicable.
- No invented price, stock, expiry, availability, certification, exclusive rights, or final terms.
- No buyer contact fields are exposed.
- Internal-review disclaimer is present.
- No external sending automation is implied.
- Korean, English, and Chinese text is preserved.

## Step B Scope

This schema document does not implement code, create or modify CSV files, create Markdown output files, create XLSX files, send quotations, automate email or messaging, scrape, search, crawl, enrich, verify, call APIs, or collect external data.
