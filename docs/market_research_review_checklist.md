# Market Research and Content Strategy Review Checklist

Use this checklist before generated market research or content strategy reports are used for internal reporting, external proposals, buyer-facing materials, public posting, or content execution.

The reviewer should mark each item as `OK`, `Needs Fix`, or `N/A`, then assign one final review result: `PASS`, `PASS WITH CAUTION`, or `FAIL`.

## 1. Source and Evidence Check

| Check item | Review status | Notes / required fix |
| --- | --- | --- |
| Does the report distinguish verified facts, observations, assumptions, and recommendations? |  |  |
| Are unverified claims clearly marked? |  |  |
| Are fake statistics, fake rankings, fake sales data, or fake sources avoided? |  |  |
| Does the report state what additional source materials are needed? |  |  |

## 2. B2B vs B2C Separation Check

| Check item | Review status | Notes / required fix |
| --- | --- | --- |
| Are B2B buyer acquisition strategies separated from consumer marketing content? |  |  |

| Are consumer-facing content ideas not confused with wholesale buyer conversion strategy? |  |  |

## 10. Review Result

| Result | Meaning | Use rule |
| --- | --- | --- |
| PASS | The report is internally coherent, cautious about evidence, and operationally usable for planning. | May be used as an internal planning document, but external claims still require verification. |
| PASS WITH CAUTION | The report is useful for internal discussion but has unresolved source, approval, compliance, localization, or execution gaps. | May be used internally but must be verified before external use. |
| FAIL | The report contains serious evidence, compliance, brand approval, fake data, or execution-readiness problems. | Must not be used externally. Fix required issues before reuse. |

## External Use Instructions

- Reports marked `FAIL` must not be used externally.
- Reports marked `PASS WITH CAUTION` may be used internally but must be verified before external use.
- Reports marked `PASS` may be used as an internal planning document, but external claims still require verification.
- Approval-required brands must not be used in external proposals, public content, or buyer-facing outputs unless explicit approval is recorded.
- Market data, channel policy claims, regulatory claims, and cosmetics efficacy claims must be verified before external use.
