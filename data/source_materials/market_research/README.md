# Market Research Source Materials

This folder stores user-provided source materials only.

No scraping, live web research, automatic web search, browser automation, API calls, or external data collection is performed by this repository.

Each research project should use a folder named by `research_id`.

Example:

```text
data/source_materials/market_research/MR-001/
```

Allowed source materials include:

- Manually collected notes
- Copied platform observations
- Screenshots described by the user
- User-provided links with descriptions
- Exported platform data provided by the user
- Internal notes
- Brand approval notes provided by the user
- Product information provided by the user

Source materials must not include guessed facts. If a report is generated without sufficient source materials, the report must mark affected findings as `검증 필요`, `소스 자료 미제공`, or `확정 불가`.

Approval-required brands must not be recommended externally unless explicit approval is provided in the source materials or approved business input.
