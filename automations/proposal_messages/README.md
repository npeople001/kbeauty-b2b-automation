# Proposal Message Generator

## Purpose

This automation generates internal-review draft proposal messages for overseas buyers from local buyer lead data, buyer scoring results, and brand approval rules.

It does not send emails, DMs, WeChat messages, WhatsApp messages, platform messages, or any external communication. It does not implement email sending, messaging automation, external sending, or platform posting.

It also does not scrape, search, crawl, enrich, verify, or automatically collect buyer data. No scraping, live web research, automatic web search, APIs, browser automation, crawlers, buyer enrichment, credit checks, requests, or external data collection are performed.

## Input Files

- `data/buyers_master_sample.csv`
- `data/buyers_scored_sample.csv`
- `data/brands_master.csv`

Buyer lead data must be manually provided or generated by earlier local automation steps. Real buyer data should remain internal-use only.

## Output Files

- `data/proposal_messages_sample.csv`
- `output/proposal_messages_sample.md`

The CSV output uses UTF-8 with BOM (`utf-8-sig`) for Excel compatibility. The Markdown output uses UTF-8.

## Standard Workflow

1. Prepare or update buyer master CSV manually.
2. Generate or update buyer scoring output.
3. Generate proposal message drafts.
4. Run the validation script.
5. Review blocked rows and compliance notes internally.
6. Confirm brand approval, MOQ, price, stock, expiry date, and claims before external use.
7. Localize Chinese, English, or Korean text if needed.
8. Do not send externally through this automation.

## Approval Block Rules

- `approval_block=true` must generate internal approval guidance only.
- `approval_block=true` must not generate buyer-facing proposal copy.
- `proposal_brand_check=approval_required_review` must be treated as approval blocked.
- `메디큐브` remains approval-required unless explicit approval is recorded.
- High score or `priority_tier=A` must not override `approval_block`.
- Approval-required brands must not appear in `recommended_brands` without explicit approval.

## Message Status Rules

- `draft_ready_for_internal_review`: draft can be reviewed internally, but it is not approved for external sending.
- `blocked_approval_required`: approval-required brand or proposal block exists; internal approval review is required before any external action.
- `needs_more_buyer_info`: key buyer information is missing or incomplete.
- `needs_moq_confirmation`: MOQ fit is `no` or `unknown`; quantity must be confirmed before proposal.
- `needs_payment_risk_review`: payment risk requires internal review before external proposal decisions.

## Message Type Rules

- `first_contact`: cautious first-contact draft for internal review.
- `follow_up`: follow-up draft when the lead status indicates prior contact or response.
- `quotation_intro`: quotation-preparation draft only; it must not include actual price, stock, expiry, or final terms unless verified.
- `product_category_intro`: category-level draft when brand recommendation is limited or safer at category level.
- `approval_review_required`: internal approval guidance only; no buyer-facing proposal copy.
- `low_priority_nurture`: low-pressure internal draft for low-priority, Hold, or not-yet-ready leads.

## Forbidden Content Rules

Generated drafts must not invent or include unsupported:

- price
- stock
- inventory
- expiry date
- official certification
- exclusive distribution rights
- contract terms
- clinical claims
- dermatological claims
- medical claims
- before/after claims
- guaranteed results
- sales rankings
- platform performance metrics
- buyer creditworthiness
- buyer authenticity
- purchase probability

## MOQ and Delivery Rules

- MOQ is generally 100+ units.
- Delivery lead time is generally 20-30 days.
- These are general business terms only, not final guaranteed terms.
- If MOQ is not confirmed, the message should request internal quantity confirmation rather than push a proposal.

## Privacy and Contact Rules

- Do not include `contact_email`, `contact_phone`, `wechat_id`, or `whatsapp` in proposal outputs by default.
- Buyer contact data is privacy-sensitive and internal-use only.
- External sharing requires permission, masking, or review.
- This automation does not perform external sending.

## Language Rules

- Chinese buyer language should generate a Chinese draft plus Korean internal notes.
- Korean buyer language should generate a Korean draft.
- English, unknown, or other buyer language should generate an English draft by default.
- Chinese and English drafts require localization review before external use.
- All outputs must include Korean internal review notes.

## Compliance Review Rules

Before any external use, manually verify:

- brand approval
- price
- stock
- inventory
- expiry date
- MOQ
- delivery lead time
- claim wording
- translation and localization
- buyer contact permission
- country-specific regulatory constraints

## Known Limitations

- Drafts are not final send-ready messages.
- This automation does not send messages.
- This automation does not verify buyer authenticity.
- This automation does not verify payment ability or creditworthiness.
- This automation does not verify stock, price, expiry, certification, or claims.
- This automation does not replace human review.
- Task 009 Quotation Maker must also respect `approval_block`, brand approval, MOQ, stock, price, and expiry verification.
